SoundManager

Unity 6.3 | C#

This sound manager is a simple packages ready to play sound in any unity projects.

Implementation

  • 1. Add the SoundManager prefab to your scene.
  • 2. On your Project window right click -> SoundManager -> newSoundData.
  • 3. a. Create a UnityEvent -> Add the SoundData SO in the event then call PlaySound().
  • 3. b. Create a SoundSource type field. Then call PlaySound().
